# Harness Examples

This directory contains small instructional harness examples for focused Turin
features and DX patterns.

Current examples:

- `reference_aware_objects/` — `_ref`-aware payload passing, `ref(...)`, and
  object-scoped actions with `action.define_on(...)`

Production-ready reusable harnesses live in:

- `library/blocks/`
- `library/workflows/`
